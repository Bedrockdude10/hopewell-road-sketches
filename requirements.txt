# Everything this repo needs, in one file, installed by one command:
#
#   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
#
# ONE FILE ON PURPOSE. The test tooling at the bottom is not split into a requirements-dev.txt,
# because a second file you have to remember is the same bug this repo has already shipped once:
# pyflakes was what tests/test_lint.py ran and it was in nobody's requirements, so the guard
# against undefined names reported success on every machine that had not installed it by hand.
# pytest was missing here too, which means the documented install has never actually been able
# to run the suite. There is no packaging step and nothing here is deployed anywhere slim, so a
# split would buy nothing and cost exactly that.
#
# Note the Blender scripts (scripts/blender/) run inside Blender's OWN interpreter and use none
# of this - see their module docstrings.
